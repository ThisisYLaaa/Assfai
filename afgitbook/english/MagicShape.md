# Magic Shape（雪花/匀速图形）完整制作教程

## 一、什么是 Magic Shape？

Magic Shape 是一种通过精确控制**轨道角速度恒定**，使星球沿一条闭合的、具有多重对称性的曲线（即“雪花”）运动的谱面技术，可用于提升谱面观赏度。
中文别名：雪花、魔法阵

- **核心特征**：每个扇区（片段）的末端与起点径向对齐，且每经过一个扇区，轨道整体旋转一个固定角度（如 60°、30°）。  
- **实现手段**：在每个扇区内，通过 BPM 变化与 Midspin（半程中旋转）来保证星球经过每个 Tile 的时间间隔相等，从而让轨道“匀速描边”出雪花形状。

---

## 二、数学原理（极坐标描述）

在极坐标系中，一个具有 \(k\) 重对称的雪花曲线满足：

\[
r(\theta) = f\!\big(k \cdot (\theta - \theta_0)\big)
\]

其中：
- \(r\) 为径向长度（距中心距离），
- \(\theta\) 为极角，
- \(f\) 是周期为 \(2\pi\) 的任意周期函数，
- \(\theta_0\) 为旋转相位。

这意味着：  
**每旋转 \(\Delta\theta = 360^\circ / k\)，径向长度重复一次**。  
因此，整个雪花可以由 \(k\) 个完全相同的“片段”首尾相接而成。

## 三、制作 Magic Shape 的完整步骤

### 步骤 0：准备基准 BPM 和目标对称重数 \(k\)

- 选定歌曲的基准 BPM（例如 150 BPM）。  
- 决定雪花对称重数 \(k\)（常见值：3, 4, 6, 8, 12）。  
- 计算每个扇区的总角度增量：\(\Delta\theta = 360^\circ / k\)（例如 \(k=6 \Rightarrow 60^\circ\)）。

### 步骤 1：设计一个扇区片段

一个片段是一段连续的 Tile 序列，需满足：

1. **起点与终点的径向方向一致**：设起点角度为 \(0^\circ\)（水平向右），则片段末端的 Tile 所在方向应为 \(\Delta\theta\)（如 \(60^\circ\)），且两个 Tile 到屏幕中心的**距离相同**（即径向长度相等）。
2. **片段内部的角度变化模式**：你可以自由设计片段的形状（如波浪、尖刺等），但必须确保片段结束时星球回到与起点相同的径向偏移。
3. **片段内的总“拍子数”**：该片段包含若干个 Tile 和 Midspin，它们共同消耗一定的拍数。这个拍数将在后续用于时间对齐。

**设计示例（\(k=6, \Delta\theta=60^\circ\)）**：

使用 30° 作为基础角增量，设计一个由 5 个 Tile 组成的片段：
```
30° Tile → 30° Tile → 30° Tile → 30° Tile → 30° Tile + 30° Midspin
```
这个组合的总角度变化：\(5 \times 30° = 150°\)，再加上最后的 Midspin（无角度变化），总旋转量不足 60°？不对——**这里的角度是星球在平面上实际移动的方向变化，不是最终扇区旋转角度**。正确理解：  
我们需要一个片段，其**平面几何路径**从 \(0^\circ\) 方向开始，结束于 \(60^\circ\) 方向，且径向长度相等。这通常需要多次方向变化（例如：30°、-30°、45°、…），最终净旋转为 \(+60^\circ\)。  
**更简单的做法**：使用纯弧线。例如连续放置多个 15° Tile，直到角度累计达到 \(60^\circ\)，每个 Tile 用特定的 BPM 来调整时间。

实际上，Magic Shape 的实现中，一个“片段”往往包含**一个 Midspin**来“消化”多余的时间，从而让净旋转等于 \(\Delta\theta\)。  
推荐一个经典模板（**30° 雪花，\(k=12\)**）：
- 普通 Tile：30°  
- Midspin Tile：0°（BPM 设为基准 BPM 的 2 倍）  
- 这是一个基本单元，重复它 12 次，就会得到一圈完整的 360° 旋转，且每 2 拍飞完 30°，角速度恒定。

**更通用的片段设计方法**：
1. 决定你想要的轨道形状（如一段“S”形曲线）。
2. 在平面直角坐标系中，用点近似这条曲线，确保起点与终点的方向相差 \(\Delta\theta\) 且径向距离相等。
3. 计算相邻点之间的角度差（逆时针为正），得到 Tile 的放置角度。
4. 通过 BPM 调节，使每两个相邻点之间的时间间隔相同。这通常需要引入 Midspin Tile 来“补时间”。

### 步骤 2：实现时间间隔相等（匀速）

匀速的核心：**每个 Tile 占用的绝对时间（秒）必须相同**。  
在 ADOFAI 中，Tile 的默认时间长度由 BPM 和角度决定。要使时间相等，常用公式：

设基准时间间隔为 \(T_0\) 秒。  
对于任意一个 Tile，其角度为 \(\alpha\)（度），则其默认时间长度为 \(\frac{\alpha}{180°} \times \frac{60}{BPM} \) 秒（因为半拍对应 180°）。  
要使其时间等于 \(T_0\)，需要调整 BPM：
\[
\text{新 BPM} = \frac{\alpha}{180°} \times \frac{60}{T_0}
\]

**标准做法**：使用 Midspin Tile（0° 旋转）来填充时间。  
- 设基准 BPM 为 \(B_0\)，则每个“普通 Tile + Midspin”组合的期望总时间为 \(2\) 拍（因为 180° 为一拍，普通 Tile 拍数为 \(\alpha/180\)，Midspin 为 0°）。  
- 为了实现每个组合时间相等，可以固定普通 Tile 的角度 \(\alpha\)，然后调整 Midspin 的 BPM 使总时间为恒定值。

**最常用的均匀化技巧**：
- 取 \(\alpha = 30°\)（普通 Tile），则它默认占用 \(30/180 = 1/6\) 拍。  
- 为了让总时间为 1 拍（或整数拍），可以添加一个 Midspin Tile，其长度为 \(5/6\) 拍。  
- 在该 Midspin Tile 上设置 BPM = \(B_0 \times 6/5\)？不对—— Midspin 本身不旋转，它的长度由 BPM 决定。正确公式：设 Midspin 占 \(x\) 拍，则 \(\frac{0}{180} \times \frac{60}{B_m} = x \times \frac{60}{B_0}\)？更简单的方法：直接用 **Set Speed** 事件。

**实际简易方法（适用范围广）**：
1. 先不管时间，按几何形状放置所有 Tile。
2. 在每个 Tile 之后插入一个 Midspin Tile（0°）。
3. 通过调整 Midspin 的 BPM，使得从上一个普通 Tile 到下一个普通 Tile 的**总时间**等于某个常数（例如基准半拍）。  
4. 可以利用 **Repeat Events** 或手动复制每个扇区。

### 步骤 3：复制扇区 \(k\) 次

- 将你设计好的一个扇区片段（含所有 Tile 和 Midspin、BPM 变化）复制 \(k\) 份。  
- 每一份在编辑器中整体旋转 \(\Delta\theta\) 即可（使用“Rotate Selected Tiles”功能）。

### 步骤 4：闭合与对齐

- 检查最后一个扇区的末端是否与第一个扇区的起点方向相同（差距应为 \(360°\) 整数倍）。  
- 如果有微小偏差，使用自定义角度微调。

## 四、完整实例：制作一个六重对称（30° 雪花）

### 目标参数
- 基准 BPM：150  
- 对称重数 \(k = 6\) → 扇区角度 \(\Delta\theta = 60°\)  
- 每个扇区包含 2 个普通 Tile 和 1 个 Midspin，总时间为 1 拍。

### 扇区设计
| Tile 类型 | 角度 | 所在 Tile 的 BPM | 备注 |
|---------|------|----------------|------|
| 普通    | 30°  | 150            | 占用 1/6 拍 |
| 普通    | 30°  | 150            | 再占 1/6 拍 |
| Midspin | 0°   | 450            | 占用 (1 - 1/6 - 1/6) = 2/3 拍 → BPM 设为 150 / (2/3) = 225?  计算错误，修正：时间为 2/3 拍，BPM = 150 × (1/(2/3)) = 225。 |
**这样每个扇区总时间为 1 拍，净旋转角度 60°**。

### 复制
- 选中这 3 个 Tile，复制 6 份，每份依次旋转 60°、120°、…、300°。  
- 将 BPM 变化也一同复制（注意相对 BPM 不变）。

### 验证
- 播放时，轨道将描出一个闭合的 6 瓣雪花，且每个扇区耗时相同。

## 五、常见问题与解决

1. **轨道不闭合**：检查最后一个扇区的结束方向是否与起点方向相差 \(360°\)。差值应能被 0.1° 容忍。  
2. **星球忽快忽慢**：BPM 计算有误。确保每个扇区的总时间相等（使用计时器验证）。  
3. **Midspin 无法对齐节拍**：可使用 **Planet Disappear** 或隐藏轨道视觉来掩盖 Midspin，或直接让 Midspin 被下一个 Tile 覆盖。  
4. **如何设计更复杂的形状？**  
   - 在几何软件中绘制图案，采样角度序列。  
   - 使用 Excel 计算每个 Tile 应占的时间，再反推 BPM。  
   - 利用 **Custom Angle** 功能手动微调。

---

## 六、进阶技巧

- **变速混合**：在某个扇区内改变基准 BPM，制造“花瓣大小渐变”的效果。  
- **非整数对称**：\(k = 3.5\) 之类的分数重数可以制造螺旋状图案。  
- **与 Pseudo 结合**：在 Magic Shape 的 Tile 上添加 Pseudo（多键同时按），极大提升难度和观赏性。
