# Song Settings

## List of Settings

|   Setting Name   |   Type Validation  |                                                          Description                                                         |
| :--------------: | :----------------: | :--------------------------------------------------------------------------------------------------------------------------: |
|     Filename     |     Audio file     | <p>Audio file for your level music <br>(<em>Accepts .ogg .mp3 .wav .aiff .aif extensions)</em><br><em>(Ideal: .ogg)</em></p> |
| Beats per minute |      Numerical     |                                                 Starting speed of your level                                                 |
|      Volume      |      Numerical     |                                        % of volume your music will be played at start                                        |
|      Offset      |      Numerical     |                      Delay in milliseconds, added to your gameplay start so it matches the audio timing                      |
|       Pitch      |      Numerical     |                          <p>Playback speed of the level in %<br><em>(100% = Original speed)</em></p>                         |
|     Hitsound     | Multiple selection |                                              Sound each tile will play when hit                                              |
|   Sound Volume   |      Numerical     |                                           % of volume each hitsound will be played                                           |
|  Countdown ticks |      Numerical     |                            Number of beats in the countdown timer until the level's starting beat                            |

{% hint style="info" %}
To calculate your <mark style="color:orange;">Beats per minute</mark> and <mark style="color:orange;">Offset</mark> correctly, head over [Finding the Correct BPM & Offset](https://adofaieditor.gitbook.io/english/know-the-basics/finding-the-correct-bpm-and-offset). These are **essential values** for your level creation!
{% endhint %}
