# Level Settings

## List of Settings

|         Setting Name         |   Type Validation  |                                                 Description                                                |
| :--------------------------: | :----------------: | :--------------------------------------------------------------------------------------------------------: |
|            Artist            |        Text        |                                            Name of the composer                                            |
|      Special Artist Type     | Multiple Selection |                          Description of the license from the Music of said Artist                          |
| Proof of artist's permission |        File        |                    Image or document proving the Artist allows the usage of their music                    |
|             Song             |        Text        |                                              Name of the music                                             |
|            Author            |        Text        |                                          Name of the Level creator                                         |
|         Portal Image         |     Image File     |                           Image for the portal display at the custom levels list                           |
|          Level Icon          |     Image File     |                              Image for the tile icon at the custom levels list                             |
|       Level Icon Color       |      Hex Code      |                                    Color range value for the icon image                                    |
|      Song Preview Start      |      Numerical     |                   The start point, in seconds, of the music during Custom Level selection                  |
|     Song Preview Duration    |      Numerical     |                  How long, in seconds, the music plays when on the Custom Level selection                  |
|        Seizure Warning       |   Radio Selection  |                     Indicate if your level can cause any issues to people with Epilepsy                    |
|       Level Description      |        Text        | Description for your level theme and gameplay style. Can be also used as a level introduction or crediting |
|          Level Tags          |        Text        |                  Single word indicators to find your level. Separate each tag with commas                  |
|         Artist links         |        Text        |                          URL info about the artist. Separate each URL with commas                          |
|  Speed Trial Multiplier Aim  |      Numerical     |                                   Sets the speed trial goal to your level                                  |
|          Difficulty          | Multiple Selection |                                     1 to 10 scoring on level difficulty                                    |

{% hint style="info" %}
In case the music has a **public license**, or you are the artist, permission is **not required** on <mark style="color:orange;">Proof of Artist's Permission</mark>
{% endhint %}

{% hint style="success" %}
For better knowledge on how to **score the difficulty** of your level, go to [Difficulty Scoring Methods](https://adofaieditor.gitbook.io/english/level-preparation-and-assisting-techniques/difficulty-scoring-methods)
{% endhint %}

{% hint style="success" %}
To fully customize your Level Titles, go to [Formatting Syles](https://adofaieditor.gitbook.io/english/level-preparation-and-assisting-techniques/formatting-styles)
{% endhint %}

{% hint style="warning" %}
These <mark style="color:orange;">Settings</mark> are **necessary** if you want to **export levels**. Go to [Export and Publish Levels](https://adofaieditor.gitbook.io/english/know-the-basics/export-and-publish-levels) to know more
{% endhint %}
