# Background Settings

## List of Settings

|            Setting Name           |   Type Validation  |                                      Description                                     |
| :-------------------------------: | :----------------: | :----------------------------------------------------------------------------------: |
|          Background Color         |      Hex Code      |                      Color range value for the background color                      |
|  Show Tutorial Background pattern |   Radio Selection  |          Choose between showing the background pattern or not in your levels         |
| Tutorial Background pattern color |      Hex Code      |                     Color range value for the background pattern                     |
|     Tutorial Background shape     | Multiple Selection |       Remove or use different variants of the background shapes in your levels       |
|  Tutorial Background shape color  |      Hex Code      |                      Color range value for the background shapes                     |
|          Background Image         |     Image File     |                            Image to act as the background                            |
|            Image Color            |      Hex Code      |                  Color range value for the background image contrast                 |
|              Parallax             |      Numerical     |      Indicate both X & Y values to displace the background from the player's POV     |
|            Display Mode           | Multiple Selection |                    Select different forms of background placement                    |
|          Image Smoothing          |   Radio Selection  |        Indicate if you allow to smooth digitally the background of your level        |
|           Lock Rotation           |   Radio Selection  |            Indicate if you allow the background to rotate with the camera            |
|          Loop Background          |   Radio Selection  | Indicate if you allow the background image to repeat itself to fill its outside area |
|           Scaling Ratio           |      Numerical     |                     How much zoom, in %, the background will have                    |
