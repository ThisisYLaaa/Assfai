# Misc Settings

## List of Settings

|        Setting Name       |   Type Validation  |                                               Description                                               |
| :-----------------------: | :----------------: | :-----------------------------------------------------------------------------------------------------: |
|      Video Background     |     Video File     |                             Video to be rolling as background while playing                             |
|         Loop Video        |   Radio Selection  |                          Indicate if you allow the video to loop after it ended                         |
|           Offset          |      Numerical     |               How long, in miliseconds, the video takes to start playing when on the level              |
|     Tile Icon outlines    |   Radio Selection  |                             Indicate if you allow the icons to have outlines                            |
|        Sticky Tiles       |   Radio Selection  | Indicate if you allow the tiles to be sticky and the tile movement forces the planets to move with them |
|     Planet Orbit ease     | Multiple Selection |                             Select how the planets rotate along each others                             |
|      Orbit Ease parts     | Multiple Selection |              Select how many times you allow the planets orbit ease action on each tile hit             |
|     Ease Part behavior    |   Radio Selection  |              Indicate if you prefer the orbit ease to repeat or mirror the current tile hit             |
|     Default Text color    |      Hex Code      |                                  Color range value for the text you add                                 |
| Default Text shadow color |      Hex Code      |                           Color range value for the shadow of the text you add                          |
|   "Congratulations" text  |        Text        |                            Custom text for when the player finishes the level                           |
|    "Pure Perfect!" text   |        Text        |                            Custom text for when the player perfects the level                           |

{% hint style="info" %}
For better knowledge on how to **score the difficulty** of your level, go to [Difficulty Scoring Methods](https://adofaieditor.gitbook.io/english/level-preparation-and-assisting-techniques/difficulty-scoring-methods)
{% endhint %}
