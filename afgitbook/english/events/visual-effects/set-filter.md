{% tab title="Event Settings" %}

| Event Setting Name |                   Type Validation                  |                                            Setting Description                                           |
| :----------------: | :------------------------------------------------: | :------------------------------------------------------------------------------------------------------: |
|       Filter       |                 Multiple Selection                 |                              Set which filter you want your screen to apply                              |
|       Set to       |                   Radio Selection                  |                                    Turn the selected filter on or off                                    |
|      Intensity     | <p>Numerical<br><em>Accepts both integers</em></p> |       <p>Select how intense you want your filter to show<br><em>Some filters are absolute</em></p>       |
|      Duration      |                      Numerical                     |                      Set for how long the filter takes to reach the desired settings                     |
|        Ease        |                 Multiple Selection                 |                   Sets which easing is used for the transition animation of this event                   |
|   Disable others   |                   Radio Selection                  |                         Select this if you need the active filters to switch off                         |
|    Angle offset    | <p>Numerical<br><em>Accepts both integers</em></p> |         <p>Used to set the start delay of the event, in degrees</p><p><em>(0º = on hit)</em></p>         |
|      Event tag     |                        Text                        | Sets a tag that indentifies this event to other events. Can be used for repetition or easy event set-ups |
