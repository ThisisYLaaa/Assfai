{% tab title="Event Settings" %}

| Event Setting Name |                   Type Validation                  |                                            Setting Description                                           |
| :----------------: | :------------------------------------------------: | :------------------------------------------------------------------------------------------------------: |
|      Duration      | <p>Numerical<br><em>Accepts both integers</em></p> |                                     Set how long the flash will occur                                    |
|        Plane       |                   Radio Selection                  |            Selected if you want your flash to affect the entire screen or just the background            |
|     Start color    |                      Hex Code                      |                               The event will start flashing with this color                              |
|    Start opacity   |                      Numerical                     |                            How transparent you want the starting color to show                           |
|      End color     |                      Hex Code                      |                                The event will end flashing with this color                               |
|     End opacity    |                      Numerical                     |                             How transparent you want the ending color to show                            |
|    Angle offset    | <p>Numerical<br><em>Accepts both integers</em></p> |         <p>Used to set the start delay of the event, in degrees</p><p><em>(0º = on hit)</em></p>         |
|        Ease        |                 Multiple Selection                 |                   Sets which easing is used for the transition animation of this event                   |
|      Event tag     |                        Text                        | Sets a tag that indentifies this event to other events. Can be used for repetition or easy event set-ups |
