{% tab title="Event Settings" %}

| Event Setting Name |                   Type Validation                  |                                            Setting Description                                           |
| :----------------: | :------------------------------------------------: | :------------------------------------------------------------------------------------------------------: |
|        Color       |                      Hex Code                      |                                   Sets a solid color for the background                                  |
|        Image       |                     Image File                     |                                           Your Background file                                           |
|     Image color    |                      Hex Code                      |                              Changes the base color of the background image                              |
|      Parallax      | <p>Numerical<br><em>Accepts both integers</em></p> |                   Changes the travel distance of the background from the camera's POV.                   |
|    Display mode    |                 Multiple Selection                 |           What looping your background will display in case the image reaches any of its edges           |
|   Image smoothing  |                   Radio Selection                  |                              Select if you want yor image digitally smoothed                             |
|    Lock rotation   |                   Radio Selection                  |                            Locks the background from rotating with the camera                            |
|   Loop background  |                   Radio Selection                  |                             Locks the background from moving with the camera                             |
|    Scaling ratio   | <p>Numerical<br><em>Accepts both integers</em></p> |                                Indicates which size the background will be                               |
|    Angle offset    | <p>Numerical<br><em>Accepts both integers</em></p> |         <p>Used to set the start delay of the event, in degrees</p><p><em>(0º = on hit)</em></p>         |
|      Event tag     |                        Text                        | Sets a tag that indentifies this event to other events. Can be used for repetition or easy event set-ups |
