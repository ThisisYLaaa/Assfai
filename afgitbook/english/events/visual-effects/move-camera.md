{% tab title="Event Settings" %}

| Event Setting Name |                   Type Validation                  |                                            Setting Description                                           |
| :----------------: | :------------------------------------------------: | :------------------------------------------------------------------------------------------------------: |
|      Duration      |                      Numerical                     |                                The amount of beats the movement will last                                |
|     Relative to    |                 Multiple Selection                 |                            Set from each POV you want your camera to work with                           |
|      Position      | <p>Numerical<br><em>Accepts both integers</em></p> |                  <p>Set the camera's new position<br><em>Works on X and Y axis</em></p>                  |
|      Rotation      | <p>Numerical<br><em>Accepts both integers</em></p> |                                       Set the camera rotation angle                                      |
|        Zoom        | <p>Numerical<br><em>Accepts both integers</em></p> |                                  Set how far your camera moves from you                                  |
|    Angle offset    | <p>Numerical<br><em>Accepts both integers</em></p> |         <p>Used to set the start delay of the event, in degrees</p><p><em>(0º = on hit)</em></p>         |
|        Ease        |                 Multiple Selection                 |                   Sets which easing is used for the transition animation of this event                   |
|      Event tag     |                        Text                        | Sets a tag that indentifies this event to other events. Can be used for repetition or easy event set-ups |
