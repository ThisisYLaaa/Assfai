{% tab title="Event Settings" %}

|  Event Setting Name  |   Type Validation  |                                          Setting Description                                          |
| :------------------: | :----------------: | :---------------------------------------------------------------------------------------------------: |
|   Hold start sound   |   Radio Selection  |                                 Enables/disables the hold start sound                                 |
|    Hold loop sound   |   Radio Selection  |                                  Enables/disables the hold loop sound                                 |
|    Hold end sound    |   Radio Selection  |                                  Enables/disables the hold end sound                                  |
|    Hold mid sound    | Multiple Selection |                            Changes the sound effect used for the hold sound                           |
|  Hold mid sound type |   Radio Selection  | Enables/disables the hold sounds repetition. Sets sounds for start, during and end of the hold action |
| Hold mid sound delay |      Numerical     |                    Sets an offset to the start of the hold sound relative to a tile                   |
|      Relative to     |   Radio Selection  |                       Selects the tile in which the audio offset is relative to                       |
|   Hold sound volume  |      Numerical     |                                       Volume of hold sound in %                                       |
|     {% endtab %}     |                    |                                                                                                       |
