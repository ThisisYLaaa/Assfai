{% tab title="Event Settings" %}

|    Event Setting Name    |                   Type Validation                  |                                        Setting Description                                        |
| :----------------------: | :------------------------------------------------: | :-----------------------------------------------------------------------------------------------: |
|         Duration         |                      Numerical                     |                       Amount of time in beats the freeroam section will last                      |
|    Freeroam area size    |                      Numerical                     |                  Area size of the freeroam section *determined by x and y values*                 |
|      Position offset     | <p>Numerical<br><em>Accepts both integers</em></p> | Sets the starting position of freeroam tiles compared to last tile *determined by x and y values* |
| Exit transition duration |                      Numerical                     |               Amount of time in beats in which the exit ending transition will last               |
|           Ease           |                 Multiple Selection                 |             Sets which easing is used for the exit transition animation of this event             |
|   Hitsound for onbeats   |                 Multiple Selection                 |                              Hitsound that will play for onbeats hits                             |
|   Hitsound for offbeats  |                 Multiple Selection                 |                             Hitsound that will play for offbeats hits                             |
|      Countdown ticks     |                      Numerical                     |                Number of beats, counting timer for the regular tiles beat to start                |
|     Angle correction     | <p>Numerical<br><em>Accepts both integers</em></p> |                      Changes the planets animation for the ending transition                      |

{% hint style="info" %}
*You can check all easing behavior on the <mark style="color:purple;">Event Skillful Formatting and Showcases -</mark>* [*Easing Showcase*](https://adofaieditor.gitbook.io/english/event-skillful-formatting-and-showcases/easing-showcase) *section*
