| Event Setting Name | Type Validation |                             Setting Description                            |
| :----------------: | :-------------: | :------------------------------------------------------------------------: |
|      Duration      |    Numerical    |      Amount of extra loops in the holds, representing extra hold time      |
|   Travel distance  |    Numerical    |      Distance between the hold starting tile and the hold ending tile      |
