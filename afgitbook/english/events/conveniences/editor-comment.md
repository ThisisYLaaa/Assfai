### Editor formatting styles

* **Bold** -> `<b>yourtext</b>`
* *Italic* -> `<i>yourtext</i>`
* <mark style="color:orange;">C</mark><mark style="color:green;">o</mark><mark style="color:purple;">l</mark><mark style="color:red;">o</mark><mark style="color:blue;">r</mark> -> `<color=red>yourtext</color>` or `<color=004400>yourtext</color>`
* Size -> `<size=100>yourtext</size>`

*As of the moment, there are several tags aside these, but they were <mark style="color:red;">not implemented</mark> to work in this event*

{% hint style="warning" %}
Formats must be closed from the **last** to the **first** one used
{% endhint %}

{% hint style="info" %}
**Purple Icons** can only be seen on the editing side. During gameplay, they disappear but work as the same
{% endhint %}
