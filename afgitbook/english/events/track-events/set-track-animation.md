{% tab title="Event Settings" %}

|     Event Setting Name     |   Type Validation  |                Setting Description                |
| :------------------------: | :----------------: | :-----------------------------------------------: |
|   Track appear animation   | Multiple Selection |   Sets the style of the tiles fade in animation   |
| Beats before for animation |      Numerical     | Sets when the animation will start based on beats |
|  Track disappear animation | Multiple Selection |   Sets the style of the tiles fade out animation  |
