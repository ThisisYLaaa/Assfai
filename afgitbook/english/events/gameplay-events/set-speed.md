*Both the Snail/Rabbit indicate a speed below/above 5% of the current speed*

*Both the Double Snail/Rabbit indicate a speed below/above 205% the current speed*

{% hint style="info" %}
The best practice for both these cases, is to only change the speed of the current BPM to half/double. In the Double Snail/Rabbit cases, to 4x times the current speed down/up.

*ie: 150 bpm -> 75 bpm (Half), 150 bpm -> 300 bpm (double)*
{% endhint %}
