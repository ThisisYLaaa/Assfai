{% tab title="Event Settings" %}

| Event Setting Name |   Type Validation  |                                                Setting Description                                                |
| :----------------: | :----------------: | :---------------------------------------------------------------------------------------------------------------: |
|        Ease        | Multiple Selection |                            Sets the easing movement for the planets rotation animation                            |
|     Ease parts     |      Numerical     |         Sets how many times the planets create the ease movement selected, every 360º *(180º = one beat)*         |
| Ease part behavior |   Radio Selection  | Select the way the planets imitate the ease movement on each part *(Repeat = same ease / Mirror = opposite ease)* |

{% hint style="info" %}
*You can check all easing behavior on the <mark style="color:purple;">Event Skillful Formatting and Showcases -</mark>* [*Easing Showcase*](https://adofaieditor.gitbook.io/english/event-skillful-formatting-and-showcases/easing-showcase) *section*
