# Favorites

{% hint style="info" %}
To add events into the <mark style="color:orange;">Favorites</mark>,<mark style="color:yellow;">`Mouse Right Click`</mark> on any event icon

To remove them from your <mark style="color:orange;">Favorites</mark>,<mark style="color:yellow;">`Mouse Right Click`</mark> on any event icon at the <mark style="color:orange;">Favorites</mark> Tab
{% endhint %}
