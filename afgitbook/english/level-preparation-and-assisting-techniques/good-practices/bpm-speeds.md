## • False speed changes

Typical game plays have an **unwritten rule** that helps keep consistency at all levels. That rule is simple: <mark style="color:green;">Speeds should always be</mark> <mark style="color:green;"></mark><mark style="color:green;">**Double**</mark> <mark style="color:green;"></mark><mark style="color:green;">or</mark> <mark style="color:green;"></mark><mark style="color:green;">**Half**</mark> <mark style="color:green;"></mark><mark style="color:green;">the tempo of the current BPM.</mark> You may also **Quadruple** or **One-fourt**h the speed as the game presents it with a double rabbit/snail

### Ways around this rule

### -> Text Indication

Indicating in text format the speed is going to change in an inconsistent way, usually helps players get prepared ahead for an irregular gameplay style, making it a great way to stop surprises
