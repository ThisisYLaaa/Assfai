# Tech Chart Playing Techniques

When play testing a Tech chart, you need to know how to play them, so here is a quick tutorial:\
To start, since the BPM is probably too high in order to only use one hand to play, you can try to use both by alternating the hand you are currently using repeatedly, demonstrated in the video below.\
\
For normal pseudos, you will need to use two keys at once, and for that, <mark style="color:red;">don't use both hands to hit two keys at once</mark>. Instead, hit two keys using the same hand, which is also demonstrated in the video below.

For harder Tech charts, only 2 keys won't be enough. Because of that, a technique called **rolling** is used, where you alternate between 4 keys or more. This technique can have many variations on how you execute it, but in the video below, the rolling goes from the outer keys (middle fingers) to the inner keys (index fingers).&#x20;
