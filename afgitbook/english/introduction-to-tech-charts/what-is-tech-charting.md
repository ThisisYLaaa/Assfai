# What Is Tech Charting?

A Tech chart is one of the two most common types of charting, with the other type being Classic charting.\
\
While Classic charting revolves around having relatively simple gameplay, relying on concepts presented in the official levels, Tech charting goes beyond, having patterns where you would need to use two or more keys at once, being them at the same time or in a sequence of each other, and more complicated patterns. Tech charts can range from requiring medium skill levels to requiring skills that only the best of the best players have.
